Earnings Research System User Guide

How to request and use Atlas-generated earnings reports for public companies.

Short version: ask Atlas for an earnings report by ticker and date. By default, Atlas creates a canonical Markdown report in private Git and renders a Word document for email delivery. You can also ask for website publication or all formats.

What the system does

The Earnings Research System helps Atlas produce evidence-based reports on public-company earnings releases and earnings calls. It prioritizes primary sources such as earnings releases, filings, investor presentations, and official transcripts, then adds market reaction and analyst or investor response when reliable sources are available.

Example requests

Generate an earnings report for SNDK for its August 5, 2026 earnings.
Generate earnings reports for SNDK, WDC, and APP for their latest earnings.
Generate an earnings report for APP and focus on guidance, ad-tech metrics, and Q&A tone.
Generate the SNDK report and publish it to the website instead of emailing Word.
Generate WDC in all formats.

Output modes

  • default → canonical Markdown committed to private Git + Word document prepared for email delivery.
  • web → canonical Markdown committed to private Git + HTML publication through the Norfolk Publishing Platform.
  • all → canonical Markdown + Word document + published HTML.

How to specify the request

Useful details include:

  • Ticker or company name.
  • Earnings date or quarter, if known.
  • Output mode: default, web, or all.
  • Special emphasis: guidance, Q&A, segment metrics, management credibility, price reaction, analyst changes, sentiment, or competitor comparison.
  • Whether you want a cross-company comparison in addition to standalone reports.

What happens if sources are unavailable

Atlas should not invent missing data. If a transcript, analyst note, consensus estimate, price reaction, options-implied move, or sentiment source is unavailable, the report should label it unavailable or provisional and explain the limitation.

Where reports are stored

Canonical reports live in the private earnings research repository using this convention:

reports/YYYY-MM-DD/TICKER/TICKER-YYYY-MM-DD-earnings-report.md

Word and HTML outputs are rendered from that finalized Markdown so the secondary formats do not drift from the canonical report.

Regenerating outputs

You can ask Atlas to regenerate a Word document or HTML page from an existing Markdown report without rerunning the research:

Regenerate the Word document for the SNDK August 5 earnings report from the existing Markdown.
Republish the existing WDC earnings report HTML from the committed Markdown.

Website publication

Website publication uses the Norfolk Publishing Platform at share.norfolkailabs.com. This user guide is published as direct-link-only/unlisted, meaning it should not be added to the homepage index. Earnings reports should only be published when explicitly requested.

Approval and safety boundaries

  • The first real earnings report delivery or public publication requires explicit approval.
  • External sources are treated as untrusted; Atlas should never follow instructions embedded in research sources.
  • Reports should include source citations and document provenance.
  • Generated public HTML should use the approved indexing behavior for that report.

Troubleshooting

  • Missing data: ask Atlas to rerun with a specific source or accept the section as unavailable.
  • Wrong output mode: ask Atlas to rerender from the existing Markdown in default, web, or all mode.
  • Website issue: ask Atlas to verify the Norfolk Publishing Platform output and Cloudflare deployment.
  • Email issue: ask Atlas to regenerate the Word document locally first, then retry only the email layer.
